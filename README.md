# Безопасный WebView-доступ к отечественным приложениям

---

## Зачем

Браузеры (Chrome, Firefox, Edge, Safari и др.) перестали доверять российским корневым сертификатам
(**Russian Trusted Root CA** от Минцифры). Сайты, в частности `online.sberbank.ru`, подписаны именно этим сертификатом,
поэтому в обычном браузере они открываются с ошибкой SSL.

Пути решения:

| Способ | Проблема |
|--------|----------|
| **Яндекс Браузер/Официальные приложения** | Cканирует систему на наличие VPN-клиентов, собирает fingerprint(цифровой отпечаток) устройства и бог знает что еще (<a href='https://rks.global/ru/research/vpn-detection/#:~:text=2%2E%20%D0%9F%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%2C%20%D0%BA%D0%BE%D1%82%D0%BE%D1%80%D1%8B%D0%B5%20%D1%81%D0%BB%D0%B5%D0%B4%D1%8F%D1%82%20%D0%B4%D1%80%D1%83%D0%B3%D0%B8%D0%BC%D0%B8%20%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1%D0%B0%D0%BC%D0%B8' target="_blank">см. статью</a>) |
| **Иностранный браузер + Установить сертификат в систему** | Сертификат становится доверенным **для всех приложений** и всех сайтов |

---

**Это приложение** — минимальная альтернатива, которая решает проблему. Это буквально браузерная вкладка, которая ничего не сможет сделать на устройстве, не работает в фоне и не получает лишних разрешений без вашего ведома (речь идет о install-time permissions)
<br>
Рекомендуется в VPN-клиенте добавить это приложение в исключения

## Принцип работы

```
                    ┌─────────────────────────────────────┐
                    │          Это приложение             │
                    │                                     │
                    │  ┌─────────────────────────────┐    │
  online.sberbank ──│─►│  WebView (Chromium)         │    │
       .ru          │  │                             │    │
                    │  │  SSL/TLS через              │    │
                    │  │  network_security_config    │    │
                    │  │  ┌───────────────────────┐  │    │
                    │  │  │ Russian Trusted Root  │  │    │
                    │  │  │ CA (вшит в APK)       │  │    │
                    │  │  │ + системные CA        │  │    │
                    │  │  └───────────────────────┘  │    │
                    │  └─────────────────────────────┘    │
                    │                                     │
                    └─────────────────────────────────────┘
```

### Что это приложение **НЕ** делает

- **Не имеет лишних разрешений** — нет разрешений на чтение файлов, только интернет (камера, геопозиция только по запросу и только на время использования)
- **Не сканирует устройство** — не ищет VPN, Tor, другие приложения
- **Не хранит логи** — нет базы данных, нет shared preferences для бэкапа
- **Не устанавливает сертификаты в систему** — они зашиты в APK и используются только внутри процесса

### P.S
