# СберОнлайн — безопасный WebView-доступ к online.sberbank.ru

---

## Зачем

Браузеры (Chrome, Firefox, Edge, Safari и др.) перестали доверять российским корневым сертификатам
(**Russian Trusted Root CA** от Минцифры). Сайт `online.sberbank.ru` подписан именно этим сертификатом,
поэтому в обычном браузере он открывается с ошибкой SSL.

Обходные пути:

| Способ | Проблема |
|--------|----------|
| **Яндекс Браузер/Официальное приложение Сбербанка** | Шпионское ПО, сканирует файловую систему на наличие VPN-клиентов |
| **Установить сертификат в систему** | Сертификат становится доверенным **для всех приложений** и всех сайтов — это огромная дыра в безопасности |

---

**Это приложение** — минимальная альтернатива, которая решает проблему без компромиссов.

## Принцип работы

```
                    ┌─────────────────────────────────────┐
                    │          Это приложение             │
                    │                                     │
                    │  ┌─────────────────────────────┐    │
  online.sberbank ──│─►│  WebView (Chromium)         │    │
       .ru          │  │                             │    │
                    │  │  SSL/TLS через              │    │
                    │  │  network_security_config    │    │
                    │  │  ┌───────────────────────┐  │    │
                    │  │  │ Russian Trusted Root  │  │    │
                    │  │  │ CA (вшит в APK)       │  │    │
                    │  │  │ + системные CA        │  │    │
                    │  │  └───────────────────────┘  │    │
                    │  └─────────────────────────────┘    │
                    │                                     │
                    └─────────────────────────────────────┘
```

### Что это приложение **НЕ** делает

- **Не имеет доступа к файловой системе** — нет разрешений на чтение файлов, только интернет
- **Не сканирует устройство** — не ищет VPN, Tor, другие приложения
- **Не отправляет данные третьим лицам** — нет аналитики, нет телеметрии
- **Не хранит логи** — нет базы данных, нет shared preferences для бэкапа
- **Не устанавливает сертификаты в систему** — они зашиты в APK и используются только внутри процесса
